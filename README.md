# Mealivery Website Replica

A personal front-end learning project that recreates the design and layout of the [Mealivery website](https://www.mealivery.com/).

## About the Project

This project was developed to practise and strengthen my front-end web development skills by replicating an existing website as closely as possible.

The goal was to recreate the original website's visual design, layout, styling, and responsive behaviour while writing the code independently.

## Technologies Used

- HTML5
- CSS3

**No front-end frameworks or CSS frameworks were used.**

## Project Purpose

This project was created for educational and portfolio purposes as part of my front-end development learning journey.
